# نظام بلاغات GPS

نظام داخلي لإنشاء بلاغات التوقف والسرعة ودخول الورش واستهلاك الديزل، مع ترقيم تلقائي ورسالة تبليغ جاهزة وسجل مركزي قابل للتصدير إلى Excel.

## المكونات

- واجهة عربية متجاوبة للمراقبين.
- Cloudflare Worker للواجهة البرمجية.
- Cloudflare D1 لحفظ البلاغات.
- تصدير السجل الحالي إلى ملف Excel.
- إمكانية حماية الموقع عبر Cloudflare Access.

## التشغيل المحلي

1. تثبيت الحزم: `npm install`
2. تطبيق قاعدة البيانات محليًا: `npm run db:migrate:local`
3. تشغيل الموقع: `npm run dev`

بعد إنشاء قاعدة D1 على Cloudflare، يوضع معرفها في `wrangler.jsonc` ثم تطبق الترحيلات البعيدة وتنشر النسخة.
