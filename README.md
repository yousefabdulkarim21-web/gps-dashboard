# لوحة متابعة GPS

صفحة داخلية عربية تقرأ ملف سجل البلاغات Excel محليًا داخل المتصفح، ولا ترسل البيانات إلى أي خادم.

## النشر على GitHub Pages

1. أنشئ مستودعًا خاصًا باسم `gps-dashboard` في حساب الشركة.
2. ارفع محتويات هذا المجلد إلى المستودع.
3. من **Settings → Pages**، اختر النشر من الفرع `main` والمجلد `/ (root)`.
4. اجعل المستودع خاصًا أو قيّد الوصول إلى موظفي الشركة فقط.

## الاستخدام

افتح الموقع، ثم اختر أحدث ملف `سجل_بلاغات_GPS.xlsx`. تظهر المؤشرات مباشرة في المتصفح.

> النسخة الحالية لا ترفع ملف Excel إلى GitHub أو أي خدمة أخرى. الربط التلقائي بـSharePoint يحتاج لاحقًا إلى موافقة تقنية المعلومات على ربط Microsoft Graph بصورة آمنة.
